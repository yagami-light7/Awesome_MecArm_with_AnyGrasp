# mecarm-anygrasp-sim

This repository provides a PyBullet-based simulation and control interface
for validating robotic grasping with AnyGrasp SDK and an external MCU-based
Cartesian controller.

## Notice

This repository does not contain AnyGrasp SDK, AnyGrasp model weights, or
AnyGrasp license files. AnyGrasp is owned by its original authors. Users must
obtain the official SDK and license from the original project.

This project only provides simulation, coordinate transformation, grasp
selection, trajectory generation, and MCU communication code.
